# Nimbo

Instaladores do Nimbo, um assistente de reunião que transcreve ao vivo, no próprio computador, o microfone e o áudio do sistema.

Baixe a versão mais recente em [Releases](../../releases/latest):

- **Windows:** `Nimbo_<versão>_x64-setup.exe`. O instalador ainda não é assinado; se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.
- **Mac (Apple Silicon):** `Nimbo_<versão>_aarch64.app.tar.gz`. Extraia e arraste o `Nimbo.app` para Aplicativos.

Depois de instalado, o Nimbo se atualiza sozinho.

Este repositório tem só os instaladores; o código-fonte não é público.
